어디에서 읽고, 무엇으로 돌려줄까?

@PathVariable은 경로에서, @RequestParam은 쿼리·폼에서 값을 읽습니다. @ModelAttribute는 쿼리·폼을 객체로 묶고, @RequestBody는 JSON 본문을 객체로 변환합니다.

Swagger UI에서는 API 명세와 응답 스키마를 확인하고 같은 요청을 직접 실행할 수 있습니다.
